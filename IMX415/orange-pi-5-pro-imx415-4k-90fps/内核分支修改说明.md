### 2) `09c9035d2`

- 标题：imx415: add 4K90 default mode and bump CMA to 512MB
- 涉及文件：
  - `arch/arm64/boot/dts/rockchip/rk3588s-orangepi-5-pro-camera1.dtsi`
  - `arch/arm64/boot/dts/rockchip/rk3588s-orangepi-5-pro.dts`

  - 配合调整 DTS 与内存相关参数（含 CMA 调整）以支撑高吞吐视频链路。

### 3) `692365c3d`

- 标题：dts: switch orangepi-5-pro cam1 overlay to rkisp0_vir0
- 涉及文件：
  - `arch/arm64/boot/dts/rockchip/overlay/orangepi-5-pro-cam1.dts`
- 说明：
  - 将 cam1 overlay 的链路切换到 `rkisp0_vir0`，统一 ISP 接入路径，减少链路不一致风险。

### 4) `4a98bd93d`

- 标题：imx415: align 4K90 register set with 37.125MHz reference
- 涉及文件：
  - `drivers/media/i2c/imx415.c`
- 说明：
  - 对齐 4K90 寄存器组与 37.125MHz 参考配置，修正高速模式下关键时钟/时序参数。

### 5) `929985ca9`

- 标题：默认回退 IMX415 到 4K 1782M 安全模式，保留 4K90 可选。
- 涉及文件：
  - `drivers/media/i2c/imx415.c`
- 说明：
  - 通过实际链路问题定位（`rkisp` 报 `CIF_ISP_PIC_SIZE_ERROR`）后，将默认模式从 2376M 回退到 1782M 稳定档。
  - 保留 4K90（2376M）模式作为可选模式，避免影响后续性能验证。
  - 目标是保证系统上电默认链路稳定可出流，同时保留高性能试验能力。
